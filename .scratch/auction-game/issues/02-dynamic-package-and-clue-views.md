# 动态包裹、网格布局与线索视角

Status: ready-for-agent

## Parent

`.scratch/auction-game/PRD.md`

## What to build

将主路径中的最小演示内容替换为由预定义藏品目录和规则配置生成的动态包裹，并完整接入玩家可见的线索视角。

包裹生成应允许目录项重复，满足包裹总价值及按珍稀度划分的价值约束。矩形藏品随机摆放在固定宽度、自动增长高度的网格中，必须非重叠且列方向无空洞。默认视图仍隐藏所有藏品信息。

实现公共线索、每轮共享候选线索集和私有结果。候选线索集内部无放回抽取、跨轮允许重复，所有玩家都能选择同一条；公共与私有线索可以信息重叠。交付珍稀度形状线索与随机完整揭示线索，并确保知识只累积在对应席位的对局内知识中。

## Acceptance criteria

- [ ] 藏品目录以配置表达矩形尺寸、珍稀度和固定具体价值；动态包裹允许同一目录项重复。
- [ ] 生成的包裹满足配置的总价值与各珍稀度价值约束，或以明确失败结果报告当前配置无解。
- [ ] 布局保持固定配置宽度、自动增长高度、矩形非重叠和列方向无空洞，且不按珍稀度形成固定位置规律。
- [ ] 默认客户端网格不泄露藏品的位置、形状、珍稀度、身份或具体价值。
- [ ] 每轮产生公共线索和互不重复的候选线索集；候选类型可跨轮重复，多个席位可选择同一类型。
- [ ] 珍稀度形状线索与随机完整揭示线索按既定可见性更新所属席位知识，不泄露其他席位的私有结果。
- [ ] 行为测试覆盖生成约束、布局不变量、线索抽取规则和席位视角过滤，而不依赖某一随机布局的具体坐标。
