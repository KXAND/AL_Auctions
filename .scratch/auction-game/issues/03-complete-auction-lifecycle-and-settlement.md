# 完整竞拍生命周期与资产结算

Status: ready-for-agent

## Parent

`.scratch/auction-game/PRD.md`

## What to build

在已有服务端主路径和动态包裹上完成所有已确认的竞拍轮规则、统一回合揭示与资产结算。

分析阶段和出价阶段均由权威倒计时驱动。分析超时放弃私有线索，出价超时提交零元。服务端按金额降序及有效出价顺序升序排名，应用配置的前四轮获胜倍数和第五轮后的倍率；零元不参与有效竞价。未成交轮不结算，全员弃拍在第五轮后持续到配置的连续弃拍上限。

成交时计算赢家利润或损失；赢家损失按配置比例以整数向下取整分给所有非赢家席位，余数离开经济系统。所有出价和选择类型只在回合揭示时统一公开，结算界面可以展示真值但不改变经济结果。

## Acceptance criteria

- [ ] 分析和出价阶段各有权威倒计时；未响应席位分别获得无私有线索和零元出价的结果。
- [ ] 多个有效出价按金额及服务端接受顺序排序；并列最高由先被权威认可者获胜，第二高出价取排名第二名。
- [ ] 单人有效竞价直接成交；零元始终是放弃竞拍；不满足倍率的多个有效出价进入下一轮且资产不变。
- [ ] 获胜倍数、第五轮后的倍率和连续弃拍上限均来自配置；第五轮后全员弃拍不会零元成交，并能以未成交结束。
- [ ] 回合揭示前，任何席位都不能得到其他席位的出价或选择类型；揭示时统一展示出价、选择类型和结果。
- [ ] 成交时赢家资产变化精确等于 `Y - Xw`；赢家损失时每个非赢家席位获得规定的整数分配，余数不分配。
- [ ] 行为测试覆盖超时、倍率边界、同价、单人有效竞价、全员弃拍、未成交结束、利润、亏损和舍入；客户端流程可展示倒计时、回合揭示和基础结算。
